# Vey kod denetimi — güncel özet

**Tarih:** 23 Ekim 2026
**İncelenen upstream başlangıç revizyonu:** `1626f550865a9694201e1f6d15cb106f49e7c14e` (`origin/main`)
**Çalışma dalı:** `main`
**Kapsam:** Rust tip denetleyicisi, JavaScript runtime/server, CLI/LSP, regresyon testleri ve mevcut dokümantasyon. Bu rapor denetim bulgularını özetler; tüm eksiklerin kapandığı anlamına gelmez.

## Bu değişiklikte doğrulanıp düzeltilenler

1. **Serbest `TypeVar` herhangi bir tipe atanabiliyordu.** `(Type::Var(_), _) | (_, Type::Var(_)) => true` kuralı kaldırıldı. Checker, etkin generic scope'larda deklarasyonla gelen type bound'ları genişletip assignability ve sayısal/string operatör kontrollerinde kullanıyor. Böylece `T` artık kendiliğinden `number` veya başka somut tip sayılmıyor; `T: number` gibi sınırlar kullanılmaya devam ediyor.
2. **`unknown`, daraltma olmadan `object` kabul ediliyordu.** `Unknown -> AnyObject` istisnası kaldırıldı. `is object` ile daraltılmış kullanım geçerli; daraltılmamış kullanım artık tip hatası.
3. **Promise olmayan `await` sonucu `any` oluyordu.** `await` Promise içini açıyor; Promise olmayan operandın tipini koruyor. Yanlış dönüş tipinin bu yoldan saklanması önlendi.
4. **Mutable alias covariance tip güvenliğini bozuyordu.** Array/tuple elemanları, dictionary key/value türleri ve yazılabilir object/named/interface alanları invariant kontrol ediliyor; bilinmeyen uzunlukta array→tuple dönüşümü reddediliyor. Fresh array/tuple/object literal'ları bağlamsal olarak hedef tipi alırken mevcut nested alias'lar genişletilemiyor.
5. **`mount.update()` node türü geçişinde effect lifecycle'ı hatalıydı.** Statik→fonksiyon geçişinde effect başlatılmıyor; fonksiyon→fonksiyon geçişinde eski bağımlılık seti yenilenmiyor; fonksiyon→statik geçişinde effect abonelikleri bırakılmıyordu. Update artık eski effect'i durdurup yeni node fonksiyonu için yeniden kuruyor.
6. **Optional route parametresi sonraki segmenti yanlışlıkla tüketiyordu.** Route matcher artık optional parametreyi önce tüketmeyi dener; kalan desen eşleşmezse parametreyi atlayarak geri döner. Başarısız `(patternIndex, pathIndex)` durumları memoize edilir. Aynı eşleştirici browser, server ve middleware tarafından kullanılır. İki yorumun da geçerli olduğu optional-before-wildcard durumunda önce tüketme kuralı korunur.
7. **Body limiti aşıldığında request stream'i ve keep-alive bağlantısı bırakılıyordu.** `Content-Length` ön kontrolü ve streaming/chunked aşımında 413 yanıtı hazırlanırken Node response keep-alive dışı işaretleniyor ve `Connection: close` gönderiliyor. Böylece yanıt flush edildikten sonra okunmamış istek gövdesi olan bağlantı güvenle kapatılıyor; saldırgan kontrollü, sonu gelmeyen bir gövdeyi drain etmeye çalışılmıyor.
8. **Statik dosya servisinde containment kontrolü ile path'i yeniden açma arasında TOCTOU vardı.** Dosya canonical path kontrolünden sonra bir kez açılıyor; `fstat` ile normal dosya ve dosya kimliği doğrulanıyor. Platform destekliyorsa açılmış descriptor'ın `/proc/self/fd` veya `/dev/fd` hedefi root içinde ayrıca doğrulanıyor; `O_NOFOLLOW` mevcutsa kullanılıyor. Tam GET stream'i ile byte-range okumaları aynı açılmış descriptor'ı kullanıyor; HEAD/304/error yollarında descriptor kapatılıyor.
9. **`res.sendFile` / `res.download` path'i kontrol ettikten sonra yeniden açıyordu.** `stat` ile alınan kimlik açılmış descriptor'ın `fstat` sonucu ile karşılaştırılıyor; yalnızca doğrulanan descriptor metadata, tam gövde ve stream için kullanılıyor. HEAD/error/erken tamamlanma yollarında descriptor kapanıyor; aktif kaynak response finish/close ile durduruluyor ve `drain` gelene kadar pause ediliyor. Stream ilk byte'ı göndermeden önce finish hook'ları çalışıyor. İndirme adlarındaki kontrol karakterleri ve header ayraçları temizleniyor; Unicode adlar ASCII fallback ve RFC 5987 `filename*` ile aktarılıyor.
10. **Harici HTTP abort sinyali retry tetikleyebiliyordu.** Önceden iptal edilmiş signal fetch'i başlatmıyor; in-flight iptal ve abort edilebilir retry beklemesi yeni denemeyi durduruyor. Genel timeout sonrası futile retry yapılmıyor ve istek tamamlanınca harici signal listener'ı kaldırılıyor.
11. **LSP rename aynı yazımdaki bağımsız bağlamları karıştırabiliyordu.** Name index artık lexical scope'larda binding kimlikleri çözüyor; rename/definition/references yalnızca aynı bağlamaya bağlı tokenları döndürüyor. Shadowing, kardeş fonksiyonlar ve assignment hedef/değerleri regresyonla doğrulanıyor. Deklarasyon tokenları ve açık import alias'ları doğru aralıkta; LSP UTF-16 sütunları giriş/çıkışta dönüştürülüyor ve token içi imleç, astral Unicode, tam identifier-range test ediliyor.
12. **LSP file URI percent-decoding'i çok baytlı UTF-8 yollarını bozuyordu.** `%xx` kaçışları byte olarak biriktirilip bütün yol UTF-8 doğrulamasından geçiriliyor; scheme büyük/küçük harf duyarsız, yerel `localhost` authority kabul ediliyor. Bozuk kaçışlar, geçersiz UTF-8, NUL, query/fragment ve uzak authority reddediliyor. Tanıların Unicode dosya URI'ları da çıkışta percent-encode ediliyor. Percent-encoded `café` dizinindeki import ve ayrıca geçerli/bozuk URI biçimleri test ediliyor.
13. **LSP framing/lifecycle ve bilinmeyen yöntem yanıtları JSON-RPC ile uyumsuzdu.** `exit` döngüyü hemen kapatıyor (öncesinde `shutdown` yoksa status 1); temiz EOF, bozuk/eksik frame'den ayrılıyor. Geçersiz frame parse error ile kapanıyor, Content-Length doğrulanıyor ve 64 MiB sınırı uygulanıyor. Bilinmeyen request `-32601`, geçersiz request `-32600` alıyor; unknown notification yanıtlanmıyor. Subprocess ve unit testleri bu davranışları kilitliyor.
14. **SSE yanıtları backpressure'a uymadığı için yavaş istemciye sınırsız event yazılabiliyordu.** `response.write()` `false` döndürürse stream ve heartbeat derhal durdurulup socket kapatılıyor; tek SSE frame'i 1 MiB ile sınırlandırılıyor. Deterministik regresyonlar `write()` backpressure sonucunu enjekte edip tek deneme/kapamayı, ayrıca oversized frame'in yazılmamasını doğruluyor.
15. **`deploy --target` eski build dosyalarını bırakıyor ve host verilerini güvenle ayırt etmiyordu.** Hedefe sürümlü, hex-kodlu sahiplik manifesti yazılıyor; sonraki deploy yalnızca eski manifestteki ve artık üretilmeyen Vey dosyalarını kaldırıyor. Unmanaged dosya çakışmaları, bozuk/traversal manifestleri, symlink'li parent'lar ve build/target path örtüşmesi reddediliyor. Dosyalar aynı dizinde geçici dosyaya yazılıp atomik rename ile güncelleniyor; hardlink alias'ı etkilenmiyor. Regresyonlar stale Vey sayfasının silinmesini, host dosyalarının kalmasını ve bu güvenlik sınırlarını kapsıyor.
16. **`migrate` dry-run değişiklik bulduğu hâlde başarılı çıkıyordu.** Dosyaları yazmayan preview artık değişiklik gerekiyorsa status 1, temiz preview ve başarılı `--write` ise status 0 döndürüyor; kaynak dosyanın dry-run'da değişmediği test ediliyor.
17. **`[build].minify=true` config'ten okunuyor ama hiçbir çıktıya uygulanmıyordu.** Güvenli bir JS/CSS/HTML/source-map minifier'ı bulunmadığından bu ayar artık sessizce yutulmuyor: site, Node ve deploy build'leri çıktı oluşturmadan açık hata veriyor. Gerçek minification ayrı özellik işi olarak kalıyor.
18. **Kısıtlı generic üye erişimi, bound yerine `any` döndürüyordu.** `T.member` artık type-parameter constraint'ini (zincirli constraint'ler dâhil) açarak alan tipini çözüyor; unbounded, bulunmayan ve döngüsel bound'daki erişimler hata veriyor. Object/interface/nested alanlar ve yanlış dönüş tipi regresyonla doğrulanıyor.
19. **Kısıtlı generic computed-index erişimi array/dictionary/union bound'larında `any` döndürüyordu.** `T: [number]` için yanlış dönüş türü ve dictionary'deki yanlış key artık geçmiyor. Computed lookup bound'ı çözüp array/tuple/string numeric index'ini, dictionary key/value türlerini, union kollarını ve literal object key'lerini denetliyor; unbounded, cyclic ve constrained non-indexable bound'lar fail-closed davranıyor.
20. **`T: U` dependent constraint'i çağrıda callee bound'larından çözülmüyordu.** `T` argümanı, `U`'nun kendisi çıkarılmamış olsa bile `U`'nun ilan edilmiş transitif bound'una karşı kontrol ediliyor; explicit ve inferred substitutions uygulanıyor. Geçerli inferred/explicit çağrılar kabul, bound'u ihlal eden argümanlar ret regresyonlarla doğrulanıyor; bound'lar tek başına type substitution'a yazılmıyor.
21. **Generic alias argümanı doğrulaması etkin generic bound'larını kullanmıyordu.** `Box<U>` ve `U: number` gibi geçerli kullanımlar `TypeChecker::fits` ile kabul ediliyor; uyumsuz caller bound'u reddediliyor.

Regresyon kapsamı: generic identity ve kısıtlı generic dönüş/aritmetik/liste kabul edilir; kısıtsız generic dönüş ve sayı işlemi reddedilir; bounded member access object/interface/nested/chained shape'lerden gerçek alan tipini alır. Generic array/dictionary/union indexing element/value/key türlerini korur ve unbounded/recursive bound'ları reddeder; `T: U` explicit/inferred çağrıları ve generic alias argümanları bound-aware kontrol edilir. `unknown` yalnızca `object` olarak daraltılınca kabul edilir; scalar `await` gerçek tipini korur; mutable-container alias ihlalleri ve `mount.update()` lifecycle geçişleri doğrulanır; optional route ve body-limit senaryoları browser/server testleriyle kapsanır; statik servis için containment/path/stream/range symlink yarışları sınanır. `sendFile` için path swap, HEAD descriptor kapanışı, yanıt timeout/finish ve client disconnect sonrası cleanup, `drain` backpressure, session cookie; `download` için kontrol karakteri sanitizasyonu ve Unicode header encoding test edilir. HTTP için pre-abort, in-flight abort, 5xx/network retry backoff iptali, toplam timeout ve listener cleanup doğrulanır. LSP rename için outer/inner/sibling scope'ları, yazma hedefi, astral identifier ve açık import alias'ının gerçek token aralıkları doğrulanır; percent-encoded Unicode file URI, malformed escapes, UTF-8 doğrulaması ve remote authority reddi de test edilir. JSON-RPC için `exit`/`shutdown`, invalid ve incomplete frame parse-error yanıtları, unknown request/notification ayrımı ve aşırı uzun Content-Length sınırı doğrulanır. SSE için backpressure'da tek yazımdan sonra socket kapanışı, heartbeat/write lifecycle ve 1 MiB üstü frame'in reddi doğrulanır. Deploy için önceki Vey manifestine göre stale dosya temizliği, unmanaged host dosyalarının korunması/çakışma reddi, build output overlap, manifest traversal, symlink parent ve hardlink alias güvenliği test edilir. `migrate` dry-run statusları ve minify fail-fast site/Node/deploy yollarında; server test harness'ı da `kill -s KILL -- -PGID` ile process group'u lideri reap etmeden sonlandırmasıyla sınanır.

## Kalan doğrulanmış riskler ve özellik sınırlamaları

### Runtime/server

Şu anda bu kategoride doğrulanmış açık yüksek öncelikli bulgu yok. SSE backpressure, HTTP caller abort, `sendFile`/`download` descriptor yaşam döngüsü ve yerel deploy hedefi senkronizasyonu regresyonlarla kapatıldı.

### CLI/LSP ve deploy

- Minification henüz desteklenmiyor; `[build].minify=true` açıkça reddediliyor ve bu davranış regresyonla test ediliyor. `T: U` dependent call constraint'leri artık callee bound'larıyla doğrulanıyor; constrained finite object üzerinde dinamik computed key ise desteklenmiyor ve fail-closed hata veriyor (literal key ve dictionary index signature çalışıyor).

Kalan maddeler açıkça belgelenmiş özellik sınırlamalarıdır; generic return-type inference'ın dependent bound'larda daha ileri genişletilmesi ayrı denetim gerektirir. LSP completion derinliği, cross-file rename/definition, codemod ve sağlayıcıya deploy gibi maddeler de tek başına bug değil, özellik kapsamı eksikleridir.
